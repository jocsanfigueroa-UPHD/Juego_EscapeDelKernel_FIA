KERNEL RUN

¿Qué es?

Objetivo del juego

Kernel Run es un juego tipo runner donde el protagonista es un hilo de ejecución que intenta escapar del caos del sistema operativo. Debes avanzar esquivando errores, evitando fallos del kernel y manteniendo la ejecución viva.

Conceptos clave

  • NullPointerException: error que ocurre cuando una referencia no apunta a nada y rompe la ejecución.
  • StackOverflow: se llena la pila de llamadas y el sistema deja de responder.
  • MemoryLeak: fuga de memoria que provoca saturación del sistema.
  • Combo: varios obstáculos superados seguidos aumentan la puntuación.
  • Boss final: enemigo grande que aparece en una fase avanzada del juego.
  • Parallax: fondo con capas moviéndose a distintas velocidades para crear profundidad.

Controles

  • Espacio o ↑: saltar.
  • ↓: agacharse para pasar por obstáculos bajos.
  • P: pausar o continuar.

Power Ups

Recoge el escudo para evitar un impacto y el temporizador para ralentizar el entorno por unos segundos. Esto te ayuda a seguir avanzando cuando el nivel se vuelve más difícil.

Historia

El personaje es un hilo de ejecución atrapado en un kernel caótico. Debe correr, reaccionar y sobrevivir a la corrupción del sistema para salir con vida del entorno digital.

KERNEL RUN

Escape del Kernel FIA

Esquiva las excepciones, recoge bonus y sobrevive al caos del sistema.

Objetivo

Evita errores del kernel y mantén vivo el hilo principal el mayor tiempo posible.

Controles

Espacio o ↑ para saltar, ↓ para agacharte y P para pausar.

Power Ups

Escudo para bloquear impactos y temporizador para ralentizar la velocidad del juego.

Desafío

Los niveles suben, aparecen más obstáculos y el boss final se activa en la fase avanzada.

  • Salta con ESPACIO o ↑
  • Agáchate con ↓ para pasar por huecos bajos
  • Pausa con P cuando lo necesites

Física con Delta Time · Colisiones AABB · Web Audio API

Controles

  • Espacio / Flecha arriba: Saltar
  • Flecha abajo: Agacharse
  • P: Pausa / Reanuda

Objetivo

Conduce al agente del hilo de ejecución a través de un corredor ciberpunk evitando:

  • NullPointerException
  • StackOverflow
  • MemoryLeak

El juego sube de nivel cada 200 puntos. Cada nivel cambia la paleta de colores y acelera los obstáculos.

Resumen

Es un juego de supervivencia con estilo cyberpunk donde debes evitar errores del sistema, recoger bonus y mantener vivo el hilo principal.

Recordatorio

Usa la pausa cuando necesites revisar la pantalla o tomar una mejor decisión para seguir avanzando.

Sugerencia

Mantén el ritmo y limpia la memoria eliminando obstáculos fuera de pantalla automáticamente.
